# Plantation Soil Monitoring System - Dashboard PRD ## Main Architecture & Navigation - **Navigation:** `st.sidebar` navigation between four tabs: 1. **Executive Overview** 2. **Historical Trends** 3. **Action Center** 4. **Future Upgrades** ## Tab 1: Executive Overview (Non-Expert View) - **Warning System:** Traffic-light style metrics using `st.columns` and `st.metric`. - **Banners:** - `CRITICAL: Irrigation System Offline (0mm)` (st.error) - `CRITICAL: Plot 1 Drought & Salinity Stress (1.0% Moisture, 4.8 dS/m EC)` (st.error) - `WARNING: Plot 2 Acidity Dip (pH 4.92)` (st.warning) - **AI Assistant:** Chatbot interface using `st.chat_message` and `st.chat_input` for farm managers to ask questions about soil health. ## Tab 2: Historical Trends & Telemetry - **Section 1:** Dual-Axis Moisture vs. Rainfall Chart (to show moisture only increases during rain). - **Section 2:** Soil Status Timeline Heatmap (Drought <10%, Normal, Wet >35%). - **Documentation:** Brief plain-English explanations for each chart. ## Tab 3: Action Center (Technician Interface) - **Interface:** Task-management/dispatch style checklist. - **Action Items:** 1. Inspect irrigation controller/pumps (0.0mm for 7 days). 2. Fresh-water flush on Plot 1 (4.8 dS/m salinity). 3. Apply pH buffer (agricultural lime) to Plot 2 (4.92 pH). ## Tab 4: Future Upgrades (Alternative Sensing) - **Visual Style:** 'Locked Premium' feature, potentially greyed out or with lock icons. - **Proposed Sensors:** 1. Multi-depth Tensiometers (15cm, 30cm, 60cm). 2. Drainage Lysimeters. 3. Automated Flow Totalizers. - **Comparison:** 'Cost of Sensor' vs 'Financial Cost of Crop Loss' for each.
